# Substance-Recovery-Assistant2
#AI Recovery Companion — a calm, GenAI-powered support app for people navigating substance use recovery.

Zero-typing check-ins, personalized emergency scripts, and an AI-written journal that remembers what actually helps.

README summary:
AI Recovery Companion An emotionally intelligent recovery support app built around one idea: help someone make the next healthier decision, not fix their whole life in one sitting. Instead of another mood tracker or chatbot, it works quietly in the background — noticing patterns, remembering what's helped before, and stepping in with something personal in the moments that matter most.

Core features

Zero-typing check-ins — tap an emotion, get a real-time AI reflection grounded in your actual history, not a generic quote

Help Now emergency mode — one button generates a personalized grounding script pulling from what's worked for you before and who you trust

AI-written journal — you don't write your own entries; the companion writes them for you from each check-in, building a private emotional timeline over time

Recovery memory — the app remembers which coping strategies actually helped and references them back to you ("walking helped last time this happened")

The Companion — a breathing, color-shifting presence instead of loading spinners or stats, so the interface itself stays calm even when you're not

Medically aware — every suggestion respects conditions set during onboarding (never recommends anything unsafe)

Tech React · Claude API (live model calls for every AI response, no mocked outputs) · persistent client-side storage

Status Core loop is functional end-to-end.

Next up: voice input, weekly cognitive summaries, and caregiver mode (consent-gated).
